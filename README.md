# ☕ Solana Blink PayFi Demo

Ini adalah proyek backend pertama gue menggunakan **FastAPI**. 
API ini menyediakan data untuk Solana Actions/Blinks yang memungkinkan pengguna "Membeli Kopi" (Donasi 0.1 SOL) langsung dari *browser* atau dompet kripto.

## 🛠️ Teknologi yang Digunakan
- Python
- FastAPI

## 🚀 Cara Menjalankan Secara Lokal
1. Pastikan Python sudah terinstal.
2. Install library: `pip install fastapi uvicorn pydantic`
3. Jalankan server: `uvicorn main:app --reload`
